04 — Documentation

Model Information

Technical overview of the prediction pipeline backing this dashboard.

CatBoostRegressor

Gradient boosted decision trees

The prediction service wraps a CatBoostRegressor trained to estimate annual medical cost from 48 demographic, clinical, procedural and policy features. Categorical fields (sex, region, plan type, and similar) are consumed directly by CatBoost's native categorical handling — no one‑hot encoding is required upstream.

01

Client Payload

Vanilla JS fetch() posts a JSON body with the 48 fields shown in the assessment form.

02

FastAPI Validation

A Pydantic model validates types and required fields before inference.

03

CatBoost Inference

The trained regressor scores the feature vector and returns a cost estimate.

04

JSON Response

FastAPI serializes the prediction back to the dashboard for display.

Prediction Target

What the model outputs

A single continuous value: projected annual medical cost in USD, rendered in the Live Estimate card on the Prediction tab.

05 — About

About This Project

Vitalis is a medical insurance cost intelligence dashboard pairing a CatBoost regression model with a FastAPI inference service. This interface handles data collection, validation, visualization and result presentation, while all scoring logic lives in the untouched backend.
